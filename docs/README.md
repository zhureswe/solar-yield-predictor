# FRP 2026 project page template (GitHub Pages)

One file: `index.html` (+ `images/`). Open it in a browser to see it.
1. Replace every `[ ... ]` with your text. Only REAL numbers (from your results.md): no number yet = delete the line.
2. Put your pictures in `images/` with the same names (teaser.jpg = your big picture, demo.jpg = your app).
3. Buttons: Paper = your PDF (put paper.pdf next to index.html), Code = your GitHub link, Demo = your live link or video.
4. Public page: no names of testers, no keys, no private photos, no songs or book texts.
5. Publish it with GitHub Pages: see the guide (a new public repository only for the page).
